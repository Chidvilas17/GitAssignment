
GIT COMMANDS USED IN THE ASSIGNMENT

1. git --version
Checks the installed Git version.

2. git config --global user.name "Chidvilas guguloth"
Configures the Git username.

3. git config --global user.email "YOUR_GITHUB_EMAIL"
Configures the Git email address.

4. git init -b main
Initializes a local Git repository with main as the initial branch.

5. git status
Displays the current repository status and changed files.

6. git add index.html about.html
Stages the initial HTML files for committing.

7. git commit -m "Initial commit: Add homepage and about page"
Creates the first commit.

8. git log --oneline
Displays the commit history in a short format.

9. git add index.html
Stages the modified homepage.

10. git commit -m "Update homepage content"
Creates the second commit.

11. git branch feature
Creates a new branch named feature.

12. git switch feature
Switches to the feature branch.

13. git branch
Displays the available local branches.

14. git add about.html
Stages the changes made to about.html.

15. git commit -m "Add new information to about page"
Commits the changes on the feature branch.

16. git switch main
Switches back to the main branch.

17. git merge --no-ff feature -m "Merge feature branch into main"
Merges the feature branch into main with a merge commit.

18. git log --oneline --graph --all
Displays the commit history and branch structure.

19. git status --ignored
Displays repository status, including ignored files.

20. git add .gitignore
Stages the .gitignore file.

21. git commit -m "Add gitignore rules for logs and temp folder"
Commits the ignore rules.

22. git add temporary_note.txt
Stages the temporary note file.

23. git commit -m "Add temporary note for undo demonstration"
Creates an additional commit for the undo demonstration.

24. git revert --no-edit HEAD
Reverts the latest commit by creating a new reversing commit.

25. git remote add origin https://github.com/Chidvilas17/GitAssignment.git
Connects the local repository to the GitHub repository.

26. git remote -v
Displays the configured remote repository URLs.

27. git push -u origin main
Pushes the main branch to GitHub and configures upstream tracking.

28. git push -u origin feature
Pushes the feature branch to GitHub and configures upstream tracking.

29. git branch -r
Displays the remote branches available on GitHub.

30. git log --oneline -5
Displays the latest five commits.
